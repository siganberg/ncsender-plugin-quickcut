## What's Changed

### ✨ New Features
- New Drill tab for drilling holes, with a preview where you can tap any hole to make it the origin
- Holding tabs on profile cuts keep parts attached to the stock
- New Keyhole shape, with an origin picker and a preview you can drag to set the Slot Angle (the Slot Angle is remembered)
- Linear, Honeycomb and Circular patterns can now be angled, and you can measure a pattern's angle from the Measure link
- The Measure page remembers its second point
- Total Angle option for Circular patterns
- Extent spacing for Linear and Honeycomb patterns, so you can set the overall span instead of the gap between copies
- Start Angle for Rectangle, and Corner Radius for Polygon
- Twist the Rectangle and Polygon previews to rotate the shape, and tap a corner to set the origin
- Shape previews show the origin crosshair and the corner radius, and inner cuts show the corner the bit leaves behind
- Number fields accept units such as mm, inches and fractions like 5/4", and feed fields also accept per-second and per-minute units
- Arrow keys step number fields like Chrome DevTools, with Shift, Alt and Ctrl or Command for larger or finer steps
- Help page for the current tab, with a link to the QuickCut page in the ncSender manual

### 🐛 Bug Fixes
- Path Direction now turns pattern copies relative to the first copy
- Starting values are converted to inches on a fresh imperial install
- Unit conversion no longer uses settings from a dialog that was opened earlier

### 🔧 Improvements
- Higher-contrast section cards, more consistent spacing and a two-row pattern card layout
- Clearer hints for the Drill origin, Keyhole Depth and the Circular pattern Start Angle
- Faster saving to the File Manager
